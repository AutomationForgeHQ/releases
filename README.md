# Automation Forge — releases

Downloadable builds of the Automation Forge plugins for Unreal Engine 5.8, one release per plugin version, packaged per engine version (`<Plugin>-<version>-UE5.8-Win64.zip`, with symbols in a separate zip).

Binaries only. The source of every open plugin lives in that plugin's own repository under this organisation; the rest is packaged on Fab. The hub and the `forge` CLI install from here through the signed manifest published in [`automation-forge`](https://github.com/AutomationForgeHQ/automation-forge).
